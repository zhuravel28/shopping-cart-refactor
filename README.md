# Shopping Cart Service Refactoring

## Опис роботи

У цьому проєкті виконано рефакторинг legacy-модуля `CartService`, який відповідає за оформлення замовлення в кошику інтернет-магазину.

Мета роботи — покращити структуру коду, розділити відповідальності, прибрати дублювання, замінити magic numbers на константи та покрити код тестами.

## Що було зроблено

- написано characterization tests для перевірки старої поведінки;
- створено окремий клас `DiscountCalculator` для розрахунку знижок;
- створено окремий клас `ShippingCalculator` для розрахунку доставки;
- винесено валідацію кошика та товарів в окремі методи;
- замінено magic numbers на named constants;
- додано обробку помилок при збереженні замовлення;
- додано unit-тести для нової логіки.

## Запуск проєкту

Встановити залежності:

npm install

Запустити тести:

npm test

## Структура проєкту

original/ — legacy-код до рефакторингу  
src/ — код після рефакторингу  
tests/characterization/ — тести старої поведінки  
tests/unit/ — unit-тести після рефакторингу  
refactoring-journal.md — журнал виконаних кроків
